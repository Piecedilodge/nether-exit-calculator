## 📖 About

Nether Exit Calculator tells you exactly where an existing Nether portal will exit in the Overworld — or where to build one to exit at a specific location.

---

## ✨ Features
<a name="features"></a>

- **Portal Link Preview** — enter Nether XZ and get exact Overworld exit.
- **Reverse Mode** — enter Overworld target and get Nether build position.
- **Existing Portal Scan** — detects nearby portals and shows their links.
- **Offset Tool** — adjust for portal frame placement differences.
- **Copy Button** — clipboard output in `/tp` format.
- **History** — saves last 10 calculations.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
